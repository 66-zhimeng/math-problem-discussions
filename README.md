# 数学问题探讨

本项目整理两个独立方向的讨论：高斯泼溅场景重建，以及设备与管道自动排布。

## 方向一：高斯泼溅场景重建

从多角度视频重建物体或房间；家具可独立移动；角色在场景内移动时不能穿墙或穿过家具。需要讨论高斯显示、独立对象、网格与碰撞体、遮挡补全的配合。

详见 [高斯泼溅建模·讨论与需求](02_高斯泼溅场景重建/高斯泼溅建模-讨论与需求.md)。目前仅讨论技术路径，用户明确要求暂不动手制作原型。

## 方向二：设备与管道自动排布

给定连接拓扑，联合安排设备、管件和管路，满足可配置的几何约束，并优化占地、长度、弯头、跨层及软规则偏差。

## 文件

两个方向各占一个文件夹：`01_设备与管道自动排布/`、`02_高斯泼溅场景重建/`。

1. [讨论过程与结论](01_设备与管道自动排布/讨论过程与结论.md)：两个方向的起点与区分，以及自动排布方向的详细讨论。为整理摘要，非逐字转录。
2. [自动排布数学模型·审查修订版](01_设备与管道自动排布/自动排布数学模型-审查修订版.md)：数学定义、目标函数、需求覆盖及第一性原理／对抗性审查。第 12 节为第三版定义收敛，优先级最高，其次第 11 节。
3. [待定定义讨论记录](01_设备与管道自动排布/待定定义-第一版提案.md)：第 10 节待定项逐轮讨论过程，结论已合并入主文档第 12 节。
4. [约束注册机制·设计草案](01_设备与管道自动排布/约束注册机制-设计草案.md)：规则模板、JSON 配置与 AI 编写、人用自然语言确认的使用流程；未实现。

6. [弯头方向枚举验证.py](01_设备与管道自动排布/弯头方向枚举验证.py)：说明仅限 90° 旋转档位时方向集合仍会增长的验证脚本。

## 当前状态

高斯重建方向尚处于技术方案讨论阶段，未制作原型。自动排布方向已完成第三版数学定义（2026-09-16），占地、高度变化、管件与变径、净距、容差、目标尺度均已定案；未选定求解算法，未实现或验证自动排布程序。规则模板与 JSON schema 用户已在另一台电脑完成；求解算法路线正在讨论。

数学建模与求解算法是自动排布方向内部的两项工作，不是本项目的两个主题。两个主题目前不预设集成关系。

资料整理于 2026-09-16，来自此前关于设备与管道联合排布的对话。
