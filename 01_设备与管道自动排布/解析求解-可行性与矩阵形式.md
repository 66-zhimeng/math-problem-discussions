# 解析求解：可行性与矩阵形式

日期：2026-09-16。依据主文档第 12 节（第三版定义）。配套脚本：`解析摆放示例.py`，输出图 `解析摆放示例.png`。

用户希望尽量得到解析解，即用矩阵运算直接写出答案。本文回答两个问题：哪些部分做得到，哪些部分做不到，以及原因。

---

## 1. 结论

**整个问题不存在一个矩阵公式能直接算出最优解。** 但问题可以严格拆成两层：

    min_X J(X) = min_{S ∈ 𝒮} f(S)

- **S：离散骨架。** 包括每对设备谁在谁左边或下方、设备朝向、每根管的转弯顺序、三通挂在哪一段、三通入口分配。
- **f(S)：骨架固定后的连续问题。** 这一层有精确的矩阵形式：
  - 只看占地时：max-plus（热带）代数的矩阵闭包，一次算出。
  - 同时考虑管长时：线性规划，最优解是某个基矩阵的逆乘右端项 x = B⁻¹b。
- **外层 min_S 无法用公式消掉**，只能搜索。这是问题固有的难度，不是方法不够好。

---

## 2. 为什么整体没有矩阵解

### 2.1 可行域不是凸集

一维最简单的情况：设备 A 固定在 [0, 1]，设备 B 宽 1，净距为 0。B 的左端坐标 x 可行，当且仅当

    x ≤ −1  或  x ≥ 1。

x = −1 和 x = 1 都可行，二者中点 x = 0 却让 A、B 重叠。**可行域不是凸集。**

任何线性方程组 Ax = b 的解集、任何凸优化的可行域都是凸集，所以无法用它们精确表达“不重叠”。“或”必须拆成若干种情形分别处理，每种情形就是一个骨架。

### 2.2 目标中有整数计数

弯头数 N_bend、高度变化次数 N_layer 是整数，由管路形状的离散选择决定，不是坐标的连续函数。

### 2.3 计算复杂度

矩形不重叠装箱的判定问题是 NP 完全问题。若存在多项式时间可算的解析公式，就能在多项式时间内解决所有 NP 问题，即 P = NP；目前普遍认为这不成立。

### 2.4 骨架数量

n 台设备有 n(n−1)/2 对，每对有左、右、上、下 4 种相对关系。n = 560 时有 156,520 对。上界为 4^156520 种组合，其中大部分自相矛盾，但剩下的合法骨架仍然多到无法枚举。

## 3. 骨架固定后：全部变成线性关系

给定 S 后：

| 约束 | 固定骨架后的形式 |
|---|---|
| i 在 j 左侧，不重叠 | x_j − x_i ≥ w_i(R_i) + δ_ee（R_i 已定，宽度是常数） |
| 端口世界坐标 | q_p = t_i + R_i q̂_p（R_i 已定，对 t_i 线性） |
| 管路从 p 到 q，第 k 段方向 d_k 已定 | Σ_k ℓ_k d_k = q_q − q_p（3 个线性等式） |
| 直管最小长度 | ℓ_k ≥ L_red + ℓ_min（常数） |
| 外接矩形 | x_i ≥ x_min，x_i + w_i ≤ x_max |
| 管长 | L = Σ ℓ_k（线性） |
| 弯头、高度变化 | 由骨架决定，是常数 |

所有约束都是差分约束或线性等式，目标只剩 A = W·H 和线性的 L。

---

## 4. 矩阵形式一：max-plus 闭包求最小占地

### 4.1 定义

max-plus 代数中，“加法”是 max，“乘法”是 +：

    a ⊕ b = max(a, b)，a ⊗ b = a + b，零元 −∞，单位元 0。

对 X 方向构造约束矩阵 M ∈ (R ∪ {−∞})^{n×n}：

    M_ij = w_i + δ_ee   若骨架规定 i 在 j 左侧
    M_ij = −∞           否则

### 4.2 解

    x* = 0 ⊗ M*，其中 M* = I ⊕ M ⊕ M² ⊕ … ⊕ M^{n−1}

M* 称为 Kleene 闭包，I 是对角为 0、其余为 −∞ 的单位矩阵。于是

    x*_j = max_i (M*)_ij = 从任一设备出发到 j 的最长约束链长度。
    W*(S) = max_i (x*_i + w_i)

Y 方向同理，得到 y* 与 H*(S)。

### 4.3 性质（可证明）

1. **可行性：** 骨架对应的约束图无正权环时，M* 存在，x* 满足全部约束。
2. **最小性：** 任何满足约束的非负 x 都有 x ≥ x*，逐分量成立。所以 x* 同时让每个坐标最小。
3. **占地最优：** W 和 H 分别由 x*、y* 取到最小值，而两个方向的约束互不相关，所以 W*(S)·H*(S) 就是**该骨架下的最小占地**，是精确解。
4. **整数性：** 输入是整数毫米时，x* 也是整数。

计算：矩阵反复平方需要 O(n³ log n)；按拓扑序动态规划为 O(n + 约束数)，结果完全相同，脚本中两种方法都算了并做了断言。

## 5. 矩阵形式二：同时优化占地和管长

占地压紧只把设备推到左下，不考虑管长。骨架固定后，在 W ≤ W*、H ≤ H* 的范围内最小化管长，是线性规划：

    min cᵀξ   s.t.  Aξ ≤ b，Eξ = e

**矩阵解的形式：** 线性规划的最优解在可行域顶点上取到。顶点满足一组起作用的约束，写成方阵 B 后

    ξ* = B⁻¹ b_B。

**限制：** 事先不知道哪组约束起作用，单纯形法就是在搜索 B。所以这是“有矩阵形式、但要算法确定 B”。

**附加性质：** 差分约束 x_j − x_i ≥ c 的系数矩阵是图的关联矩阵，属于全幺模矩阵。右端为整数时，LP 顶点自动是整数，不需要额外的整数约束。

若目标改为二次形式（例如 Σ c_ij ‖p_i − p_j‖²），且起作用约束已知，最优解由 KKT 线性方程组直接给出：

    [ Q  Aᵀ ] [ ξ ]   [ −c ]
    [ A  0  ] [ λ ] = [  b ]

## 6. 矩阵形式三：用特征向量生成初始骨架

骨架不能用公式求，但可以用矩阵方法得到一个合理的初值。

**拉普拉斯矩阵：** 连接权 c_ij 为两设备间的管道根数（或管径加权），

    L = D − C，D = diag(Σ_j c_ij)。

**谱摆放：** 忽略设备尺寸和不重叠，

    min tr(Pᵀ L P)  s.t.  PᵀP = I，Pᵀ1 = 0

解为 L 第 2、3 小特征值对应的特征向量 P = [v₂, v₃]。连接紧密的设备在 P 中坐标相近。按 P 的相对位置给每对设备定左右或上下，就得到骨架。

**有固定设备时的二次摆放：** 把设备分为自由 f、固定 a，

    p_f = −L_ff⁻¹ L_fa p_a

这是一次线性方程组求解，是严格的闭式解。L_ff 稀疏正定，560 台设备的规模可在毫秒级完成（尚未实测）。

**局限：** 它最小化的是“连接平方长度”，不考虑尺寸和不重叠，所以只能作为骨架初值。

## 7. 复制组的矩阵表达

用户确认：冷水主机 + 冷冻水泵 + 冷却水泵组成制冷链模块，复制 4 份；多台冷却塔组成一个组。

**阵列参数化：** 同一模块的 m 个副本摆成阵列时，

    t_k = t₀ + a_k d₁ + b_k d₂，(a_k, b_k) 为整数行列号。

未知量从 m 个位置减少为 t₀、d₁、d₂。仍然是线性关系，可以直接放进第 3–5 节。

**对称带来的退化：** 4 条完全相同的链在拉普拉斯矩阵中完全对称，特征值会重复。示例中特征值 4 出现 3 次，谱方法无法区分它们的先后，只能按编号排列。所以复制组更适合用阵列参数化，不要交给谱排序。

## 8. 示例结果

`解析摆放示例.py`：冷却塔组、4 个制冷链模块、分水器、集水器、定压补水，共 8 个块、18 根连接管，净距 800 mm。只摆设备，不布管；管长用中心间曼哈顿距离估计。

| 方案 | W (mm) | H (mm) | 面积 (m²) | 管长估计 (m) |
|---|---|---|---|---|
| 谱骨架 + max-plus 压紧 | 14300 | 23800 | 340.3 | 203.0 |
| 谱骨架 + LP 管长优化 | 14300 | 23800 | 340.3 | 171.3 |
| 人工骨架（链 2×2）+ 压紧 + LP | 12800 | 14600 | 186.9 | 151.6 |

三个方案都通过了不重叠检查。

**结论：**

1. 同一骨架下，LP 在不增加占地的前提下，把管长估计从 203.0 m 降到 171.3 m。
2. 换一个骨架后，**使用同样的解析步骤**，占地从 340.3 m² 降到 186.9 m²。
3. 解析部分在给定骨架下是精确的；**解的好坏主要取决于骨架**，而骨架只能搜索。

## 9. 对求解器设计的影响

最终方案：**外层搜索骨架，内层完全用解析 / 线性规划计算**。

1. **骨架表示：** 采用经典的序列对（sequence pair）表示，即两个设备排列。任意一对排列都对应无矛盾的左右 / 上下关系，从而避免约束图出现正权环。
2. **骨架初值：** 复制组用阵列参数化；其余设备用谱摆放或二次摆放定初始相对位置。
3. **每一步评估：** 交换两个设备在排列中的位置，或调整一个复制组的行列数，然后用 max-plus 最长路重算 W、H。计算量是线性级，可以每秒评估大量候选（尚未实测）。
4. **精修：** 对较好的骨架做 LP，优化管长。
5. **搜索策略：** 模拟退火或大邻域搜索，可以一直运行、随时输出当前最好解。这符合用户“没有时间上限，只要有最后结果”的要求。
6. **布管：** 管路转弯顺序也是骨架的一部分，仍按《求解算法-讨论草案.md》第 4 节的 A* 与协商布线确定。确定后，管段长度同样适用第 3 节的线性关系。

这一路线不能证明全局最优。它能保证：**输出的每个方案，在其骨架下的占地是精确最优的**，并且硬约束全部满足。
