# 设备与管网自动排布：数学模型审查修订版

版本：2026-09-16。用途：保存已确认需求、修正数学漏洞，供继续讨论。本文是问题定义，不是已实现的求解器，也不宣称已经得到最优布局。

**第三版（2026-09-16）：** 新增第 12 节，收敛了第 10 节全部待定定义。优先级：第 12 节 > 第 11 节 > 第 1–10 节。

## 1. 已确认的范围

1. 面向建模平台，联合布置有体积、有端口的设备、管件及连接管路。
2. 输入 JSON 给定完整连接拓扑，包括三通连接哪些对象。布置过程中不擅自增删逻辑连接。
3. 三通的两个入口可以交换所接支路：谁接直通入口、谁接斜向入口可以选择。不能因此推导为三个端口均可任意互换。
4. 支持直角三通和 45° 斜三通。真实端口位置、方向和管件尺寸由管件模板给定。
5. 设备可以锁位置、锁朝向、限制移动轴、限制允许区域或朝向集合；各项独立配置。
6. 支持对齐、间距、顺序、等间距、对称等可选规则。启用且设为硬约束时必须满足。
7. 支持完整标准模块：设备、内部管路、内部管件、相对布局全部复制。默认只允许平移，可配置整体旋转；内部不重新优化。
8. 目标保留：布局占地、总管长、弯头数量、跨层次数、明确启用的软规则偏差。
9. 当前不计算支撑／管架／吊架成本、穿墙成本、流量、压降、能耗、热损失、应力或载荷。
10. 分组、粗细尺度、并行和分解是待讨论的求解策略，不作为额外工程限制加入模型。

## 2. 旧稿中的主要漏洞及修正

| 旧表述 | 问题 | 本版修正 |
|---|---|---|
| 集合距离 ≥ 0 就是不碰撞 | 普通集合距离在重叠时也等于 0，条件恒成立 | 不重叠独立表达；净距另加距离条件 |
| 设备基准点在区域内即可 | 基准点在内，实体仍可能越界 | 约束整个实体或包络包含于区域 |
| 相邻设备坐标差就是设备间隙 | 忽略尺寸、朝向、基准点选择 | 对齐与中心排序用坐标；表面间隙用实体距离或投影区间 |
| 模块内部偏移直接相加 | 整体旋转时偏移也必须旋转 | 使用刚体变换组合 |
| 三通三口任意置换 | 用户只确认两个入口可换；可能改变指定出口 | 使用输入给定的允许映射集合 |
| 管件夹角满足就能连接 | 未限定端口相对位置、实体、口径和方向符号 | 使用完整管件模板与端口位姿 |
| 端点切向只要求平行 | 平行包含反向，可能向设备内部出管 | 规定有向单位切向相等 |
| 折线方向变化都计为弯头 | 三通分支不是弯头；离散采样点也不是弯头 | 按实际独立弯头构件计数 |
| 所有对象的包围盒面积最小化 | 加入固定房间／障碍物后面积可能成为常量 | 只对指定设计对象集合计算布局包围面积 |
| 占用标志设为 1 就算经过走廊 | 标志没有绑定几何，约束可以虚假满足 | 先定义经过／包含语义，再与几何双向绑定；本版不默认启用 |
| 所有规则都让求解器自由关闭 | 求解器可能关掉难约束获得低代价 | 规则模式由用户输入确定，不能自行关闭 |
| 规整度项加软约束罚分 | 同一偏差可能重复收费 | 规整性统一进入软约束项，仅计一次 |
| 隐藏模块内部即可独立并行 | 内部形状变化、跨组碰撞和目标可能仍耦合 | 是否可分解需检查全部跨组约束和目标项 |
| 线性化就能保留原问题最优性 | 离散化、近似包络及候选截断可能改变可行域 | 精确等价变换与近似模型必须区分 |

## 3. 输入、变量与派生量

### 3.1 固定输入

- 逻辑连接图 G：连接对象及其逻辑端口，允许的管件角色映射。
- 实体模板 B_i^0：对象在局部坐标中的几何形状。
- 端口模板：局部位置 q̂_p、外法向单位向量 û_p，以及口径／连接类别。
- 场地 Ω、固定障碍物集合、需要保留的禁入区域。
- 模块模板、内部成员及固定局部位姿、内部管路几何、对外端口。
- 尺度单位、坐标轴、允许姿态、管径、管件尺寸、净距参数。
- 每条规则的作用对象、参数、模式、容差、软偏差尺度与权重。

规格已给定时属于输入；只有用户明确允许选择时才引入规格选择变量。

### 3.2 独立决策变量

1. 自由对象或模块的位置 t_i ∈ R³。
2. 其允许的旋转 R_i ∈ SO(3)，满足 R_iᵀR_i=I、det(R_i)=1。
3. 可变管件的端口映射 σ_f ∈ Π_f。
4. 外部连接管路的几何 Γ_e，以及需要时的实际弯头构件及数量。
5. 允许选型时的离散规格变量。

管路段数是否可变、最大构件数量如何限定，尚未确定。不能在公式中悄悄把段数固定成任意值，再称其为完整原问题。

### 3.3 派生量

世界实体：B_i={R_i b+t_i : b∈B_i^0}。

世界端口：q_p=R_i q̂_p+t_i；u_p=R_i û_p。

模块成员的位姿、端口、几何由模块变换得到，不应同时当作无约束的独立变量。

## 4. 数学约束模板

不强行限定模板数量。一个工程要求可以由多条数学约束组合；多个工程要求也可以复用同一模板。

### 4.1 变量取值域与锁定

位置：t_i∈D_i。朝向：R_i∈A_i。

位置锁定：t_i=t̄_i。朝向锁定：R_i=R̄_i。

仅沿指定直线移动：t_i=t₀+α_i a，其中 a 为指定单位方向。

仅允许平移的模块：R_g=R̄_g。是否允许旋转由输入配置决定，不是求解器选择是否遵守的变量。

### 4.2 刚性关系与标准模块复制

成员局部位置、旋转固定为 t̂_gi、R̂_gi：

    t_i = t_g + R_g t̂_gi
    R_i = R_g R̂_gi

同一模板的各实例共享所有局部设备、内部管路、管件、外部端口数据。

若模板内部管路为 Γ̂，实例中的管路为 R_g Γ̂+t_g。

模块默认不缩放、不镜像。镜像不属于 SO(3) 中的旋转，且可能需要不同手性的真实设备／管件；如将来需要，应作为独立模板或明确几何选择处理。

### 4.3 对齐、顺序、间距与对称

对齐：x_i=x_j、z_i=z_j，可选其一或同时启用。

按 Y 轴顺序：y_j−y_i≥ε；ε 为指定正间隔或容差。它只定义基准点顺序。

等间距：y_(i+1)−y_i=d；d 可以是输入常量，也可以是带范围的共享变量，需明确。

实际表面间隙必须使用 4.4；只有已知尺寸和朝向时，才可精确换算为基准点间隔。

关于固定平面 nᵀx=c 的基准点对称：

    t_j = t_i − 2n(nᵀt_i−c)，其中 ‖n‖=1。

这只表示位置对称。外观几何对称还需要 B_j=H(B_i)，H 是该反射；不能把反射矩阵直接当合法旋转矩阵。若仅要求朝向对应，应另给合法朝向配对关系。

固定平面／固定方向下的部分关系是仿射关系；平面或方向也可变时，不再自动是线性约束。

### 4.4 不重叠、净距与包含

对禁止碰撞的实体对 (A,B)：

    int(A) ∩ int(B) = ∅。

该式允许表面接触。如不允许接触，使用严格正净距或规定的数值安全余量。

普通集合距离定义：dist(A,B)=inf{‖a−b‖ : a∈A,b∈B}。

净距要求：dist(A,B)≥δ_AB；δ_AB>0 时同时排除接触和重叠。δ_AB=0 时必须保留独立不重叠条件。

包含：B_i⊆Ω。禁入：与禁入实体满足不重叠／净距约束。

已连接管件允许在指定接合面接触，不对接合面要求额外正净距；其余几何仍需检查。不能一概豁免相连对象全部碰撞。

模块包围盒可用于保守避障，但会禁止其他物体进入盒内真实空隙；精确模型应保留成员实体并集或更精细包络。

### 4.5 端口与固定连接

直接接合的两端口 p、q：

    q_p=q_q；u_p=−u_q；Compatible(p,q)=true。

连接管路从 p 参数化到 q：

    Γ_e(0)=q_p；Γ_e(1)=q_q。
    τ_e(0)=u_p；τ_e(1)=−u_q。

τ 是有向单位切向。输入中的逻辑端口通过允许映射对应实际端口，拓扑仍保持不变。

JSON 中连接关系应有唯一权威定义；如设备与管道两侧重复记录，导入时检查一致性、端口占用和悬空连接。

### 4.6 三通端口映射与真实几何

每个三通由局部实体与三个局部端口完整定义。统一刚体变换自动保持端口间距离和夹角。

允许映射：σ_f∈Π_f，Π_f 是与流向和规格兼容的双射集合。

按当前需求，两条逻辑入口 a、b 可映射到物理直通入口与斜向入口；逻辑出口 c 保持映射到指定出口。是否扩大到其他映射，另由输入明确。

45° 的符号以模板的外法向定义为准：支口与主管某一外法向为 45°，与反向端口为 135°。不能同时要求与主管两端都是 45°。

从三通斜口伸出的直管不额外计作弯头；后续若用独立弯头转向，则计入弯头数量。

### 4.7 管路连续性、直段、弯头与实体

几何由真实直管段和管件组成；折线可以是设计骨架，但圆弧弯头必须根据实际弯曲半径替换拐角。

直段单位方向属于允许集合 U_e；该集合必须包含所选管件端口需要的方向，否则模型可能无解。

> **第三版更新：** 直管方向固定为 U₆ = {±X, ±Y, ±Z}；对象之间必须经过直管；自动同心变径。见 12.3。


相邻构件在连接面满足位置和方向条件。直段连接面之间的实际长度 ℓ≥ℓ_min。

弯头半径 ρ∈允许集合，或 ρ≥ρ_min；圆弧切去的直段长度需要计入几何，不能先按尖角算净距再认为真实弯头也合格。

管道实体由各段实体与管件实体组成。恒定圆截面沿中心线扫掠可表示直管／圆弧管，三通、法兰等应使用各自实体。

保温厚度计入实体一次；表面净距另行加入，避免把同一净距在双方包络里重复膨胀。

> **第三版更新：** 不单独建保温层，按管道最外层表面计算；净距与检修区见 12.6。


### 4.8 层级及可选路径范围

> **第三版更新：** 不再预设层标高；高度变化按实际几何计数，见 12.4。本小节中“层是显式输入的标高”的表述作废。

层级是显式输入的允许标高或标高带，而非每一个离散采样点。

管路具有层内段和过渡段。层内段归属某标高层；过渡段连接不同层。

跨层统计约定：压缩连续重复的层标签后，统计相邻不同层之间的过渡次数。一次直接从第一层到第三层，暂按一次过渡计；若要按跨越边界数计，需改定义。

连续斜段不能靠多加或减少采样点改变跨层计数。

坡度不是当前必需项。如启用，对非竖直段使用有向高差／水平长度；竖直段单独定义，避免除零。

### 4.9 离散选择与条件逻辑

需要选型时：y_ik∈{0,1}，Σ_k y_ik=1；选择规格后，几何和参数同步绑定。

条件规则：condition(X) ⇒ constraint(X)。其中条件可能来自固定属性，也可能来自合法的设计选择。

“开关由用户配置”与“模型选择某个管件从而触发规则”是两种不同语义。

此处不预先指定大 M、MILP 或其他编码方法；这些属于求解实现，任意取一个大常数不构成可靠数学定义。

## 5. 规则启停、硬软及违反度

每条用户可选规则 r 的模式 m_r∈{off,hard,soft} 是固定输入。

不等式 g_r(X)≤0 的违反度：v_r=max(0,g_r(X))。

等式 h_r(X)=0 的违反度：v_r=|h_r(X)|；向量等式需指定范数和各分量尺度。

带容差 ε_r 时，等式违反度可用 max(0,|h_r(X)|−ε_r)。

- off：本次不加入规则，也不收费。
- hard：要求 v_r=0。
- soft：在目标函数中计入归一化违反度。

几何重叠若要软化，必须定义穿透深度或重叠体积等可用违反度，不能用恒为零的重叠集合距离。

变量定义、模板几何、逻辑一致性属于模型语义，不是可随意罚分放宽的规则。将碰撞等规则关闭或软化时，输出可能是有碰撞的草案，应明确标记，不能称为满足全部几何要求的可行布局。

## 6. 当前目标函数

    min J(X) = w_A A(X)/A₀ + w_L L(X)/L₀
             + w_B N_bend(X)/B₀ + w_C N_layer(X)/C₀
             + Σ_(r为soft) λ_r v_r(X)/s_r。

所有权重非负；A₀、L₀、B₀、C₀、s_r 是正的尺度参数。归一化使米、平方米、次数和角度等不同量纲可比较。

### 6.1 布局占地 A

> **第三版更新：** 参与对象为所有设备与管道，取 XY 外接矩形，另加长宽比规则；见 12.5。

先指定参与计量的设计实体集合 D：自由设备、模块实例、管件和连接管路；排除房间、固定环境和禁入区。模块成员只计算一次。

工作定义：D 的水平投影外接矩形面积。

    A=(x_max−x_min)(y_max−y_min)。

边界必须包住 D 中全部实体。固定且相距很远的设计对象可能使面积不再变化，这是指标的真实结果。

外接矩形面积与实体投影并集面积不同。后者对不重叠固定形状的设备可能几乎不变，通常不能表达压缩布局。

水平平面暂按 XY、竖向按 Z；“总面积”最终采用外接矩形、凸包还是其他边界，仍需确认。外接矩形面积含乘积，并非自动线性目标。

### 6.2 总管长 L

按每条物理管路实际中心线弧长求和，每个物理段仅计一次；不把多条源到汇路径中共享段重复累加。

真实弯头弧长可计入。三通内部长度如何计量需统一约定，不能用三通中心与端口距离随意重复收费。

锁定模块的内部长度是常量，可以计入报告；计算时可去掉常数，不影响最优选择。

### 6.3 弯头数 N_bend

> **第三版更新：** 第一版只有 90° 弯头计数；见 12.3、12.8。

统计实际独立弯头构件；三通不是弯头，管路采样点不是弯头。45° 与 90° 弯头当前各计一次，可后续明确不同权重。

### 6.4 跨层数 N_layer

依 4.8 的显式层级过渡定义计数。权重为零或功能关闭时，不参与目标。

### 6.5 规整偏差

平行、对齐、对称等仅在用户设为 soft 时计入一次。例如：

- X 对齐偏差：|x_i−x_j|。
- 无向轴平行偏差：1−(u_iᵀu_j)²。
- 指定平面下基准点对称偏差：‖t_j−H(t_i)‖。

不能把“未设硬约束”自动解释为“必须收费”：off 就完全不参与。

## 8. 求解分块讨论：保留为思路

原问题没有天然的上层／下层。分块由变量、约束和目标的依赖关系决定，不由设备尺寸自动决定。

可将问题写成 min F(b,z₁,…,z_K)，其中 b 是块间共享变量，z_k 是块内变量。

只有在固定 b 后，全部硬约束分为各自的 C_k(b,z_k)，且目标可写为 F₀(b)+Σ_k F_k(b,z_k)，各块才真正条件独立，可分别求解。

跨组碰撞、全局占地边界、共同对齐规则、共享路径和软偏差都可能造成耦合。连接少不代表耦合少，外部端口也不是唯一边界信息。

必须区分：

1. 用户定义的刚性标准模块：内部已经固定，不需要再次求解。
2. 求解器临时把自由对象聚成一块：内部仍可变，不能未经授权把相对位置永久锁死。

第二类若先求一次就固定，会收缩原可行域，可能遗漏更好的甚至唯一可行的全局方案。其边界要包含足够的几何占用、端口条件及成本信息，必要时允许重新分块、扩大区域或反馈修改。

分解、并行、精确求解、启发式均未定案；没有实测数据支持速度承诺，也不保证任意分块都收敛。

## 9. 数学难度与可证明性边界

- 含离散选择和非凸几何时，通常不能由一次线性代数运算得到解析解。
- 可以研究精确优化方法，但不能承诺任意规模快速证明全局最优。
- 固定候选路线、有限朝向或保守包络得到的最优，是该受限模型中的最优；未必是连续真实几何问题的最优。
- 非线性物理已移除，但任意旋转、圆管碰撞、欧氏长度和面积乘积仍可能非线性。
- 全局最优证明需有效下界与正确模型；普通局部优化结果不自动有全局差距保证。
- “可行”“当前最好”“已证最优”“超时未找到”“已证无解”必须分开报告。

## 11. 第一性原理与对抗性审查：第二轮

### 11.1 结论与判断标准

**前稿覆盖了大部分需求，但尚未构成语义闭合、可直接实现的数学问题。** 缺口主要在几何、拓扑和坐标之间的绑定，以及目标的精确定义。下列补充属于本文件的修订；与前文概括表述不一致时，以本节为准。

本次从三个条件检查，而不以“约束有多少类”判断完备性：

1. 表达充分：用户允许的布局能够用变量表示，不能无意排除。
2. 可行性正确：任何满足全部硬约束的解都符合选定的布局规则，不能混入假连接、自相交等非法方案。
3. 评价一致：物理布局相同，换一种采样、编号或重复引用方式，目标值应保持不变。

这里只能针对已明确的需求检验，不能证明覆盖未来所有行业需求。第一版保留纯几何与布局范围，不引入压降、承重等新要求。

### 11.2 从实物结果倒推统一模型

一份结果必须唯一确定以下四件事：

1. 每个实体是什么形状、放在哪里。
2. 哪些实体的哪些端口相接，以及哪些连接明确禁止。
3. 每条逻辑连接由哪些真实直段和管件实现。
4. 每条用户规则是否满足、五类目标分别是多少。

据此记独立变量为 X，统一几何构造为 Φ(X)，固定逻辑图为 G，用户配置为 θ：

    求 X ∈ D(θ)
    满足 S(X; G, θ)                     [几何构造与连接语义]
         g_r(X; θ) ≤ 0，h_r(X; θ) = 0  [启用的硬规则]
    最小化 J(X; θ)。                    [第 6 节五类指标]

S 不是另一个任意开关：它要求端口、模块、规格、实体和连接图的解释一致。所有碰撞、尺寸和目标都从同一个 Φ(X) 计算，不能一处使用骨架、一处使用另一套未绑定的实体。

### 11.3 反例一：连接数量正确，却接错口或偷偷产生新分支

**攻击：** 两条管路都接到同一物理入口；或管路中途相交，被显示器当成一个额外三通。仅检查每条管路的两个端点，不能排除这些情况。

**补充约束：**

1. 为每条逻辑连接 e 定义有序物理构件链 P_e；链相邻构件满足接合条件。
2. 普通物理端口的已连接端点数等于输入要求的占用数，通常为 1；未使用端口必须由输入明确允许。
3. 不同 P_e 不得共享真实管段，除非该共享段在输入拓扑中有唯一身份；分支必须由已给定的分支构件实现。
4. 将实际连接图中仅表示直管、弯头的度为 2 节点压缩后，所得带端口角色的图必须与 G 一致；保留用户命名的中间对象。
5. 允许的表面接触不自动构成逻辑连接，接合只能发生于指定配对端口。

### 11.4 反例二：同一根管道穿过自己

**攻击：** 只检查“不同管道之间”的碰撞，一条管道的后半段可穿过自己的前半段。整体扫掠并集会隐藏重叠的来源。

**补充约束：** 将管路展开为物理构件，所有禁止相交的构件对都参与检查，包括同一管路内不相邻的段、内部模块构件与外部管路。相邻构件仅豁免指定的接合区域，其余部分仍需无碰撞。

管道外形采用外部占用包络，不能因空心管的材料壁不相交就允许另一根管子穿进其内部。若输入是零厚度三角面，int(A) 可能为空，不能直接使用第 4.4 节的实体内部公式；必须形成封闭占用体，或使用明确的表面相交与距离规则。

### 11.5 反例三：位置和轴向正确，接口仍装不上

**攻击：** 非圆接口或有定位孔的接口，沿轴旋转一定角度后，位置与法向仍满足，但接口不匹配。

**补充定义：** 一般端口使用完整局部坐标架 Q̂_p∈SO(3)，世界坐标架 Q_p=R_i Q̂_p。直接连接需满足：

    q_p=q_q，Q_pᵀQ_q ∈ K_pq。

K_pq 是包含对接翻转及允许绕轴转动的相对姿态集合。圆形且可自由绕轴旋转的接口，可退化为前文的外法向条件；不对所有端口强加无意义的绕轴锁定。

### 11.6 反例四：相同的对齐公式在旋转模块后含义改变

**攻击：** 用户要模块内部的 X、Z 一致，系统却按世界 X、Z 约束；或比较不同模型文件中的任意原点，得到看似对齐而外形不齐的结果。

**补充定义：** 每条位置、方向、对齐、顺序、对称规则必须指定参考坐标系 F 和作用特征点／轴。局部特征点 a_i 的世界位置为 p_i=R_i a_i+t_i；在参考系中的坐标为：

    p_i^F = R_Fᵀ(p_i−t_F)。

对齐等公式作用于 p_i^F，而非默认作用于对象原点。固定朝向、模块相对朝向、轴平行是不同关系。参考系可固定，也可绑定模块；后一种会增加变量耦合，但不改变规则含义。

### 11.7 反例五：模块内部复制正确，但重复编号使连接和计数出错

**补充约束：**

1. 模块模板定义固定的成员与内部连接图；每个实例有独立实体身份和端口身份。
2. 每个实例的对外端口明确映射到一个内部真实端口，不能另建未相连的虚拟端点。
3. 刚性成员只属于一个直接父模块；嵌套模块形成无环层次，变换按父子链组合。
4. 对齐组等“规则作用集合”可以交叠，但不等同于刚性父模块。
5. 内部管路、弯头只实例化并计数一次；旋转和平移不能改变内部局部几何。

### 11.8 反例六：目标函数被表示方式操纵

| 攻击方式 | 必须补足的定义 |
|---|---|
| 把固定设备排除占地集合，忽略其与自由设备之间的布局跨度 | 第 6.1 节的 D 应为明确选定的设计对象，可包含固定设备；排除的是环境，不是所有固定对象 |
| 将设备竖向堆叠，大幅降低 XY 面积 | 需明确允许的 Z 域；若对象必须在指定平面放置，以位姿域表达。不能默认自由悬浮，也不能擅自禁止用户允许的空间布置 |
| 将一条管拆成更多段，改变长度、弯头或跨层统计 | 依据实际几何和构件身份计数，与采样点、JSON 拆分无关 |
| 让管路离开再进入同一层，中途称为“过渡段”，跨层计数归零 | 层内段和过渡段必须由几何判定绑定；高度带、间隙区域、边界归属、合法过渡形状都需给定 |
| 因层带重叠而自由换标签，降低跨层罚项 | 同一实际几何应有确定归属，或事先明确多重归属的物理意义；不能把任意标签变化当物理优化 |
| 给同一批对象重复建规则，罚项翻倍 | 明确规则身份与重复规则处理；同一物理偏差不能因数据重复而重复收费 |
| 某组有很多对象，成对罚项数量平方增长，压倒其他目标 | 软规则需明确按对求和、按组平均或取最大值；三者不同，归一化不自动解决数量效应 |

因此，跨层数目前仍不是完全闭合的指标。层级几何未定义前，只能保留符号 N_layer，不能宣称已有唯一可计算公式。面积采用 XY 外接矩形也仍是暂定口径。

最大间隙若启用可写 dist(A,B)≤D，但它只表示最近两点不太远；若意图限制两个指定端口或中心的距离，应约束对应特征点距离，不能混用。

### 11.9 反例七：约束冲突被软化或“无解”结论掩盖

**攻击：** 同一对象同时锁在两处；固定模块内部已经碰撞；两个不同实例被错误认作同一对象。系统随后通过改变硬规则得到一个结果，声称求解成功。

**补充要求：**

1. 输入层检查单位、实体身份、模板引用、端口占用、固定位置与规则冲突。
2. 硬规则不能自动改成软规则；矛盾时明确报告不满足哪些规则。
3. 结果附各项指标、硬规则残差／碰撞检查结果；数值容差属于输入契约。
4. 仅在已有证明时报告无解；限时没有找到解不是无解。

这不是添加物理成本，而是确保输出与输入数学问题一致。

### 11.10 解是否存在，以及分解会不会改题

前稿未限定路径构件数，也未完全限定空间域，因此不能直接断言最小值一定能取到。严格间距不等式还可能使最优值只有下确界。

一个便于论证的充分设置是：有限构件组合、位置域有界且闭、旋转域闭、所有可行性关系闭、目标连续或下半连续，并且可行域非空。此时才可以据相应紧性条件论证最小值存在。它是充分设置，不是唯一建模方式；构件数上限可能排除原有方案，必须公开标注，不得暗中添加。

“间隙超过 d”在数值模型中应明确为 ≥d 还是 ≥d+ε，不能含糊地使用严格大于。

分解仍只是求解策略。若临时把一组设备固定内部布局，其结果只针对受限子问题；要保持原问题的表达能力，必须允许解除临时固定、调整块间边界。并行局部各自最优不推出联合最优。

### 11.11 覆盖与剩余缺口

1. **已覆盖：** 固定拓扑、设备与管路联合布置、两入口映射、真实三通、设备自由度、可选硬软规则、对齐／间隙／对称、完整模块复制、五类目标、分组求解与硬模块的区别。
2. **本次补齐：** 实际连接图与逻辑图一致性、管路自碰撞、端口完整姿态、规则参考系、模块实例身份与外部接口绑定、指标对表示方式不敏感、无解与输入矛盾的区别。
3. **仍需参数化后才能闭合：** 占地口径、放置高度域、层级与过渡的几何定义、实际管件库、允许路径复杂度、净距与容差、软项聚合及权重。它们可以成为配置项，不要求所有场景使用同一数值。
4. **未作承诺：** 当前不是完整实现，也未证明某求解器能在指定规模内求解。对这些未定参数作选择之前，不能声称模型已完全完备或能直接计算唯一答案。

**优先级：本节 > 第 11 节 > 第 1–10 节。** 前文与本节不一致处，已在对应位置加注“第三版更新”。

### 12.1 平台模型与项目配置分离

1. **平台模型**保持一般性：设备位置三维可变、旋转属于 SO(3)，允许叠放和悬空；项目差异通过规则和配置表达。
2. **项目参数不写死。** 以下参数均由项目配置给出，内核不含隐含默认值；缺失时报错：

| 参数 | 含义 | 所在小节 |
|---|---|---|
| D_default | 默认管径 | 12.3 |
| c_ρ | 弯曲半径系数 | 12.3 |
| L_red(D₁,D₂) | 变径段长度（公式或查表） | 12.3 |
| ℓ_min | 最小直管长度 | 12.3 |
| K | 每条连接高度变化次数上限 | 12.4 |

### 12.2 放置自由度

- **平台：** t_i ∈ R³，R_i ∈ SO(3)，范围由 4.1 节的位姿域配置。
- **本项目配置：** z_i = z̄_i（落在安装面）；启用“禁止叠放”规则；R_i 只绕竖轴，角度 ∈ {0°, 90°, 180°, 270°}；模块同样处理。
- 叠放启用时需补“支撑关系”定义（地面 / 指定支撑对象顶面 / 悬挂方式），待有项目需要时展开。

### 12.3 管路几何与管件

**方向与连接**

1. 每个直管段方向 τ_s ∈ U₆ = {±X, ±Y, ±Z}。不存在斜向直管。
2. 所有设备端口、管件对外端口的世界方向 ∈ U₆。
3. **任意两个物理对象（设备、弯头、三通）之间必须经过至少一段直管**，包括设备端口与管件之间。对象不能直接对接。
4. 管件安装姿态绕管轴按 90° 一档旋转，且须满足第 2 条。

**管件库**

5. **弯头：** 只有 90° 弯头。第一版不包含独立 45° 弯头（其出口为斜向，无法接直管）。
   - 口径 D_bend = 两侧所接管道口径的较大者。
   - 弯曲半径 ρ = c_ρ · D_bend。
6. **三通：** 直角三通、斜三通。
   - 斜三通的 45° 斜段及随后的 45° 弯属于模板内部几何：参与碰撞，但对外端口方向 ∈ U₆，对外等效为直角连接；斜段可朝水平方向或 Z 向。
   - 口径 = 三个所接管道口径的最大值。第一版不设异径三通模板。
7. **管径：** D_e = 输入中连接 e 的管径；未给出时取 D_default。设备端口口径 d_p 来自设备模板。

**自动变径**

8. 直管段端点所接端口口径 ≠ D_e 时，在该端点自动生成**同心变径段**。
   - 变径段属于该直管段，不是独立对象，也不是决策变量。
   - 长度 L_red(D_large, D_small)。
   - 参与碰撞、净距、外接矩形与总管长；不计弯头，不计跨层。
9. **最小直管长度：**

       len(s) ≥ L_red,start(s) + L_red,end(s) + ℓ_min

   两端无变径时对应项为 0。

### 12.4 高度变化（跨层）

替代 4.8 节“层是显式输入的标高”的表述。**不预设层标高，管道水平段高度是连续变量。**

1. 把外部连接 e 的物理路径按顺序分解为水平段与竖直段（12.3 保证没有斜段）。
2. 去掉两端的**端口接入段**：从端口到第一个水平段、从最后一个水平段到端口的竖直部分。
3. 记相邻两个水平段高度 z_a、z_b，若 |z_a − z_b| > ε_z，计一次高度变化；中间连续的竖直段合计一次。

       N_layer(e) = #{相邻水平段对 (a,b) : |z_a − z_b| > ε_z}
       N_layer = Σ_e N_layer(e)

4. 计数只依赖实际几何，与分段方式、编号、标签无关。升上去再回到原高度计 2 次。
5. **规则模板 `max_height_changes`：** N_layer(e) − K ≤ 0，对选中的连接逐条检查；本项目启用为 hard。启用后可行域缩小，报告须注明。
6. 撤销：“总管等高”规则（输入中不标记总管，无可作用对象）。

### 12.5 占地

替代 6.1 节的计量集合与口径。

1. 参与对象：**所有设备与所有管道（含管件、变径段）**。模块不单独处理，其成员照常参与。排除墙体、环境障碍物、禁入区、检修区。
2. 世界 XY 轴对齐外接矩形：

       W = x_max − x_min，H = y_max − y_min，A = W·H

   只取矩形，不对投影面积求和或求并，投影重叠不重复计数。
3. **规则模板 `aspect_ratio_max`（κ ≥ 1）：**

       W − κ·H ≤ 0，H − κ·W ≤ 0

### 12.6 净距、接触与检修区

替代 4.7 节关于保温厚度的表述，细化 4.4 节。

1. 净距按对象最外层表面计算；管道外径由输入给定，不单独建保温层。
2. 三类净距：设备–设备 δ_ee、设备–管 δ_ep、管–管 δ_pp。
3. **检修区**：挂在设备上的实体，随设备刚性变换；与其他设备、管道满足不重叠。两个检修区默认允许重叠，可配置为禁止。
4. 仅配对端口的接合面豁免碰撞检查。

### 12.7 数值容差

ε_len、ε_ang、ε_z 均为必填配置。约束统一写作 ≥ / ≤，不使用严格不等号（见 11.10）。

### 12.8 目标函数

采用加权和（替代 6 节中未定的尺度取值）：

    J = w_A·A/A₀ + w_L·L/L₀ + w_B·N_bend/B₀ + w_C·N_layer/C₀ + Σ_(r∈soft) λ_r·v_r/s_r

1. **尺度**默认由输入确定性计算，与布局无关，可在配置中覆盖：

| 尺度 | 计算 |
|---|---|
| A₀ | 所有设备模板在安装姿态下的 XY 投影面积之和 |
| L₀ | 连接数 × √A₀ |
| B₀ | 连接数 |
| C₀ | 连接数 |

2. **N_bend** 只统计 90° 弯头；斜三通及其内部 45° 弯不计。替代 6.3 节。
3. **软规则聚合**（mean / max / sum）按每条规则配置。
4. **本项目优先级：** 面积与管长优先，其次弯头与高度变化，即 w_A、w_L 大于 w_B、w_C。具体数值待定。

## 13. 研究和代码参考（不作为本轮数学审查依据）

- [InstantPipes](https://github.com/leth4/InstantPipes)：可视管道生成与寻路；不是已证全局最优的工业布局系统。
- [PipeWiringOptimization](https://github.com/yeyeleijun/PipeWiringOptimization)：A* 与多管冲突加罚原型；前次查看示例为 5 根管、21³ 格点、未启用障碍物，不能推导为规模上限或性能保证。
- [From Multi-Agent Pathfinding to 3D Pipe Routing](https://harabor.net/data/papers/bddhkw-fmapft3dpr-socs20.pdf)：优先级搜索与单管优化；工业实验最大实例含 207 根管。未确认完整官方系统公开可运行代码。
- [PBS 公开实现](https://github.com/Jiaoyang-Li/PBS)：通用多智能体寻路代码，不是该工业管线系统；其许可证限教育、研究及非营利用途，商业使用需要另行授权。
- [公开柔性布管基准模型](https://github.com/MiniZinc/mzn-challenge/tree/develop/2017/routing-flexible)：存在 MiniZinc 模型文件，但不是上述完整系统；该目录的复用许可仍需单独核实。

当前交付只整理模型与审查结果，尚未实现、部署或基准测试自动排布软件。
