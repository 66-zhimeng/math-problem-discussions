# 形式化求解：从第一性原理重新审视

日期：2026-09-16。依据主文档第 12 节、《解析求解-可行性与矩阵形式.md》。配套脚本：`精确最优对照.py`。

目的：不预设“骨架搜索 + 解析压紧”就是最好方案，从问题本身的数学结构出发，列出其他形式化解法，比较它们能给出的保证。

---

## 1. 先把问题还原到最小的数学结构

### 1.1 变量只有两类

| 类别 | 内容 |
|---|---|
| 离散 σ | 每对设备的相对方位、朝向、每根管的转弯序列、三通挂接段、三通入口分配 |
| 连续 ξ | 设备坐标、管段长度、高度 |

### 1.2 约束只有三种形式（第三版定义下）

| 形式 | 例子 | 数学类别 |
|---|---|---|
| 差分约束 ξ_j − ξ_i ≥ c | 不重叠（方位已定）、净距、外接矩形、最小直段 | 差分逻辑（Difference Logic） |
| 线性等式 | 端口坐标、管段向量和等于端口差、阵列复制 | 线性实数算术 |
| 析取 ∨ | “i 在 j 左 ∨ 右 ∨ 下 ∨ 上”，管段方向 6 选 1 | 命题逻辑 |

### 1.3 目标

- A = W·H：唯一的非线性项，但 W、H 各自只由差分约束决定。
- L：线性。
- N_bend、N_layer：由离散变量决定的整数。

**关键观察：** 这是一个**“命题逻辑 + 差分 / 线性算术”的组合问题**。已有成熟的理论专门处理这种结构。上一版的 max-plus 压紧，正好就是其中“差分逻辑理论求解器”的内核。

---

## 2. 精确基准：先知道真正的最优解

`精确最优对照.py` 用析取 MILP（大 M 编码，HiGHS 求解）对 8 块算例求最小占地：固定 W 上限、最小化 H，以 100 mm 步长扫描 W。

| 项目 | 结果 |
|---|---|
| 全局最优占地 | W = 12800，H = 14600，**186.9 m²** |
| 上一版人工骨架 + max-plus | 186.9 m²，恰好是最优值 |
| 上一版谱骨架 + max-plus | 340.3 m²，比最优多 82% |
| 求解用时，无对称性破除 | 141.4 s（扫描 181 个 MILP） |
| 求解用时，4 条链加字典序对称性破除 | 81.7 s |

结论：

1. 骨架固定后的解析压紧没有损失，差距全部来自骨架选择。与上一版的判断一致。
2. 朴素的大 M 模型只有 8 块时就要一分钟以上，无法直接扩展到数百台设备。
3. 对称性破除在这个小算例上节省约 42% 的时间。

以上用时为本机一次运行结果，只用于相对比较。

## 3. 其他形式化路线

### 路线 A：SMT / CDCL(T)，逻辑与算术联合推理

**原理：** 用 SAT 求解器决定离散方位 σ，用差分逻辑理论求解器检查 σ 是否可行：

1. SAT 部分给出一组方位选择。
2. 理论求解器建约束图，求最长路，也就是上一版的 max-plus 压紧。
3. 若图中有**正权环**（例如 A 在 B 左、B 在 C 左、C 又在 A 左），说明矛盾。取环上的方位选择，生成一条学习子句：“这几个选择不能同时成立”。
4. SAT 部分回溯，今后永远不再尝试任何包含该矛盾的组合。
5. 优化：对 W、H 做二分，或使用带优化的 SMT（OMT）。

**与模拟退火的本质区别：**

| | 模拟退火 | CDCL(T) |
|---|---|---|
| 搜索 | 随机游走，会重复访问 | 系统搜索，学到的冲突永久剪枝 |
| 完备性 | 无 | 完备：能证明最优或无解 |
| 结束时能说什么 | “目前最好是 X” | “最优是 X”，或“最好 X，下界 Y，差距 Z%” |

**工具：** Z3、OptiMathSAT；OR-Tools CP-SAT 的惰性子句生成原理相近。本机当前均未安装，尚未实验。

### 路线 B：逻辑 Benders 分解，精确处理“摆放—布管”耦合

上一版的“第 3 层反馈”是启发式的。逻辑 Benders 分解把它形式化：

    主问题：选择摆放 (σ_place, ξ_place)，目标用 A + 管长下界 L_lb
    子问题：摆放固定后布管，得到真实 L、N_bend、N_layer，或判定不可布
    割平面：
      不可布   → 排除导致冲突的那组方位选择（no-good 割）
      代价偏高 → 加入“这组方位选择成立时，布管代价 ≥ 实际值”的下界割

**保证：** 子问题精确求解时，主问题下界不断上升、可行解不断下降，两者相遇时即为**整体全局最优**。子问题用启发式时，仍能得到有效的可行解和下界，但不再保证收敛到最优。

**关键是割要“小”：** 布管失败往往只与少数几台设备的相对位置有关。从拥堵区域提取最小冲突集合，割才能排除大量摆放方案。

### 路线 C：下界理论，给出最优性证书

无论用哪种搜索，都应同时计算下界，这样才能报告离最优还有多远。

| 指标 | 可证明的下界 | 依据 |
|---|---|---|
| 管长 L | Σ 连接两端端口的曼哈顿距离，加上端口朝向所需的最小绕行 | 轴对齐路径长度 ≥ 各坐标差之和 |
| 三通管网长度 | 直角 Steiner 最小树长度 | Hanan 定理：直角 Steiner 最小树可以只在端点坐标构成的网格上求得 |
| 弯头 N_bend | 由两端端口方向与相对位置查表得出的最少转弯数 | 轴对齐路径的方向变化分情况计数 |
| 占地 A | 所有设备（含净距、检修区）的面积之和；外接矩形不能小于最宽、最深的设备 | 面积守恒 |
| 骨架下的占地 | 部分方位已定时，对已定部分做 max-plus 最长路 | 最长路只会随新约束增加 |

这些下界可以直接用于**分支定界**：部分骨架的下界已经超过当前最好解时，整个分支剪掉。

### 路线 D：对称群约化

4 条完全相同的制冷链可以任意互换编号，布局本质相同。所有等价布局构成置换群 S₄ 的轨道，每个轨道只需搜索一个代表。

- **方法：** 加字典序约束（本次实验已采用），或只在轨道代表上分支。
- **效果：** 理论上搜索空间缩小为 1/4! = 1/24；冷却塔组内 k 台相同塔再缩小为 1/k!。
- **本次实测：** 只在全局扫描上节省了约 42%，远小于 24 倍，因为大 M 模型的主要耗时不在对称性上。

### 路线 E：连续解析松弛（电场密度法）

大规模芯片摆放（ePlace、RePlAce、DREAMPlace，可处理数百万单元）的主流方法：

1. 把设备看作电荷，面积密度 ρ(x, y) 看作电荷分布。
2. 解泊松方程 ∇²ψ = −ρ。周期边界下用快速傅里叶变换有闭式解：ψ̂(ω) = ρ̂(ω) / |ω|²。
3. 电场力 −∇ψ 把重叠的设备推开；管长用光滑的对数—指数和近似。
4. 用 Nesterov 加速梯度法迭代，最后用 max-plus 压紧消除残余重叠。

**优点：** 核心计算是矩阵 / FFT 运算，最接近“解析解”的直觉，而且规模扩展性最好。
**缺点：** 没有最优性保证；对大尺寸差异、强规则（对齐、阵列复制）处理较弱。本问题分组后块数不多，它的规模优势用不上。

### 路线 F：参数化布局族（领域第一性原理）

制冷机房的结构高度规则：若干完全相同的制冷链沿分水器、集水器排开，冷却塔组靠近冷却水侧。可以把布局限定为一个参数族：

    链的行数 r、列数 c、链朝向、分集水器位于阵列哪一侧、冷却塔组位于哪一侧、行列间距

离散参数只有几十到几百种组合，**可以全部枚举**；每种组合下的间距用 LP 或 max-plus 精确求解。

**保证：** 在该布局族内精确最优，且求解很快。
**风险：** 族外的布局被排除。按主文档 11.10 节，结果必须标注为“受限模型的最优”。可以把它作为初始可行解和上界，再交给路线 A 或 B 在全空间中改进。

## 5. 推荐的组合

各路线不互斥。推荐按“先降维、再精确、全程报差距”组合：

1. **降维（D + F）：** 复制组合成刚性块，并做对称性约化；用参数化布局族快速得到第一个可行解作为上界。
2. **精确主问题（A）：** 用 CDCL(T) 在骨架空间中系统搜索，理论求解器就是 max-plus 最长路；正权环产生学习子句。
3. **耦合（B）：** 摆放作为主问题、布管作为子问题，布管失败或代价偏高时生成 Benders 割。
4. **全程下界（C）：** 结合曼哈顿距离、Steiner 树和最少弯头的下界，持续报告“当前最好解 / 下界 / 差距”。
5. **保底：** 模拟退火保留为预热手段，给主问题提供更好的上界。

与上一版相比，最大的变化是：**从“能随时给出好解”升级为“能随时说明这个解离最优还有多远”，规模允许时还能证明最优**。
